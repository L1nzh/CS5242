# Project Plan
A Modular Deep Learning Framework for Lightweight Image Recognition CS5242 Group 09 Project

1. Project Motivation
Image recognition is a core computer vision task. Instead of only reproducing a standard model, our project studies how several simple plug-and-play modules can improve a lightweight baseline in a controlled and interpretable way. This makes the project suitable for a team setting: the baseline can be kept simple and reproducible, while each team member studies one concrete architectural improvement.

2. Project Description
We will build a lightweight image recognition system on the Oxford-IIIT Pet dataset. We will first implement a simple baseline, with complete data preprocessing, training, validation, testing, and evaluation. We will then add three independent modules: Module 1, Module 2, and Module 3. Each module will be tested individually and compared fairly under the same setting.

3. Proposed Solution
The project contains one baseline and three modular extensions:
• Baseline: implement the simplest working model and full training pipeline.
• Module 1 : study its motivation, add it to the network, and evaluate its effect.
• Module 2 : implement a second improvement and compare it with the baseline.
• Module 3 : implement a third module and analyze its benefit and cost.
• Integration: compare the baseline, each single-module version, and the best combined model.
Evaluation will include standard quantitative metrics, learning curves, and concise ablation studies. The final goal is a clear comparison showing how each module affects performance.

4. Expected Deliverables
• a reproducible baseline model and training pipeline;
• three independently implemented improvement modules;
• ablation results for each module and one final comparison table;
• runnable notebook with results presentation slides.
